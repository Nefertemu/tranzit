# Tranzit

Панель каскадных пробросов портов: трафик приходит на ваш сервер-вход и уходит на сервер выхода.
Веб-панель, команда в терминале, проверка серверов и тревоги в Telegram. Без рекламы, без внешних
зависимостей: Python из системы и nftables.

## Установка

На сервере-входе (Debian 12+, Ubuntu 22.04+), от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Nefertemu/tranzit/main/install.sh)
```

Если репозиторий закрытый — с ключом GitHub, которому разрешено читать этот репозиторий:

```bash
export GH_TOKEN=<ключ>
bash <(curl -fsSL -H "Authorization: token $GH_TOKEN" https://raw.githubusercontent.com/Nefertemu/tranzit/main/install.sh)
```

Установщик напечатает адрес панели и пароль. Пароль показывается один раз.
Сертификат панели самоподписанный — браузер один раз предупредит, это ожидаемо.

Обновление — `tranzit update` (или та же команда установки). Правила, пароль и настройки сохраняются.

## Что умеет

- Пробросы TCP, UDP или оба сразу; один порт или диапазон; порт выхода может отличаться от порта входа.
- Заготовки: WireGuard / AmneziaWG, VLESS / Xray, MTProto, своё правило.
- Включение и выключение правила без удаления, счётчики трафика по каждому правилу (переживают перезагрузку).
- Не даёт занять порт, который на сервере уже слушает локальная служба (SSH, сама панель).
- Серверы выхода: название, заметка, страна и провайдер по кнопке, задержка и её история.
- Тревоги в Telegram: сервер не отвечает, ожил, задержка выше порога. Команды боту: `/status`, `/rules`, `/ping`.
- Резервная копия одним файлом и восстановление из неё.
- BBR и ограничение MSS включаются сами.

## Команды

```
tranzit                     состояние и неполадки
tranzit panel               адрес панели
tranzit passwd              сменить пароль панели
tranzit list                правила и трафик
tranzit add udp 51820 203.0.113.10          проброс на тот же порт
tranzit add tcp 443 203.0.113.10:8443       проброс на другой порт
tranzit off <id> / on <id> / del <id>
tranzit apply               заново загрузить правила в ядро
tranzit show                показать текст правил nftables
tranzit update              обновить
tranzit uninstall           удалить и снять пробросы
```

## Как устроено

- Правила лежат в своей таблице nftables `ip tranzit` и заменяются целиком одной транзакцией:
  чужие правила (Docker, ufw, другие панели) не трогаются.
- Панель слушает случайный порт по HTTPS на секретном пути; без пути сервер отвечает 404.
  Пять неверных паролей — пауза пять минут.
- Наружу программа ходит только в Telegram (если бот включён) и в справочник ipwho.is — по кнопке «Где он?».

| Путь | Что там |
|---|---|
| `/opt/tranzit` | программа |
| `/etc/tranzit/state.json` | правила, серверы, настройки |
| `/etc/tranzit/panel.json` | порт, путь и хеш пароля панели |
| `/etc/tranzit/tls/` | сертификат панели |

Служба: `systemctl status tranzit`, журнал: `journalctl -u tranzit -n 50`.

## Разработка

Панель запускается на любом компьютере без root — правила при этом не применяются:

```bash
TRANZIT_ETC=./dev-etc TRANZIT_DRY=1 TRANZIT_HTTP=1 python3 -m tranzit init
TRANZIT_ETC=./dev-etc TRANZIT_DRY=1 TRANZIT_HTTP=1 python3 -m tranzit serve
```
